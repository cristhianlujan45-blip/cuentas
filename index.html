📺 Música en el TV

1) Cuando quieras, toca «📥 Cargar en mi lista de YouTube Music»: las canciones pedidas se agregan a tu lista por turnos entre mesas. 2) Abre la lista en YouTube Music en tu celular y envíala al TV con el botón de transmitir. Las que pidan después las subes con el mismo botón.

🔊 Reproducción automática

La app reproduce sola las canciones en orden justo, una tras otra, y las que piden los clientes entran solas a la cola. Deja esta pantalla abierta con el celular encendido y con volumen.
Reproducir automáticamente

Cómo se reparte

Cada mesa puede pedir hasta 10 canciones; cada cupo se libera 15 minutos después de pedirlo. La cola va por turnos: suena una canción de cada mesa y luego vuelve a empezar, así nadie acapara la música. ▶ abre la canción en YouTube.

▶ YouTube Music automático

Cómo obtener el Client ID (una sola vez) 1) En console.cloud.google.com crea un proyecto. 2) Habilita «YouTube Data API v3». 3) En «Pantalla de consentimiento de OAuth» elige Externo y agrega tu correo como usuario de prueba. 4) En Credenciales crea un «ID de cliente de OAuth» tipo Aplicación web y en «Orígenes de JavaScript autorizados» pon la dirección https donde tienes esta app (sin / al final). 5) Copia el Client ID aquí. Para que la app busque y reproduzca sola solo necesitas una «Clave de API» (Credenciales → Crear credencial → Clave de API, limitada a YouTube Data API v3): no caduca cada hora. El Client ID solo hace falta para copiar las canciones a la lista de YouTube Music. No funciona si abres la app como archivo del celular: debe estar en esa dirección https. La conexión dura cerca de 1 hora; después toca Conectar otra vez.

🔔 Alertas con el celular bloqueado

Un navegador no puede avisar con la pantalla apagada. Para eso usa la app gratuita ntfy: cada pedido, cuenta o canción te llega como notificación con sonido aunque esta app esté cerrada.
1. Instala ntfy (Play Store o App Store) en el celular donde quieres las alertas.
2. Toca 📲 Abrir en ntfy. Si no abre, en ntfy toca +, deja el servidor ntfy.sh y pega el canal.
3. Toca 🔔 Enviar prueba: debe sonar en el celular aunque esté bloqueado.
4. En los ajustes del celular deja las notificaciones de ntfy activadas (en Android, sin ahorro de batería).
El canal es como una contraseña: no lo compartas. La alerta solo avisa; para confirmar o despachar el pedido abre la app.
