⚙️ Lo que ven TODOS los negocios

Se publica en el archivo vento-config.json (rama vento-config de GitHub). La app de cada negocio lo lee al abrir y cada hora. Tarda 1 a 5 minutos en llegar.

Un negocio suspendido no puede hacer ventas nuevas (igual que con la suscripción vencida). Sus datos y pedidos no se borran.

🔐 Permiso para publicar (una sola vez)

  1. En GitHub: tu foto → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → cuentas. Permissions → Contents: Read and write.
  3. Copia el token y pégalo aquí abajo. Queda guardado SOLO en este equipo.
